# Models and Licenses

This repository does **not** bundle detector weights.

The detector interface is model-agnostic. An optional Ultralytics adapter is provided for users who deliberately install the YOLO extra and supply their own license-plate weights. Ultralytics licensing and the license of any selected weights must be reviewed for the intended use, especially commercial deployment.

Before distributing or deploying weights, record: model name/version, source URL, code license, weights license, redistribution terms, and any commercial-use implications. Never assume that a downloadable checkpoint is automatically redistributable or commercially licensed.
